# 阅读向视觉提案

这是 `main` `23cfe234583ec06004767db1f99f085c940beaa5` 上的隔离预览。它不包含 PR 20、21、22、23，也不是线上版本。目标是文字优先、留白和低装饰，不是另一套品牌皮肤。

## 字体

不加载字体文件，也不使用 CDN。界面和正文共用系统无衬线栈，中文排在拉丁系统字体之后，避免中文落到细衬线或缺字：

`ui-sans-serif, system-ui, -apple-system, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Noto Sans CJK SC", "Noto Sans SC", "Source Han Sans SC", "Microsoft YaHei", sans-serif`

这些字体随操作系统授权，本仓库不再分发。代码用 `ui-monospace, "SFMono-Regular", "Sarasa Mono SC", "Noto Sans Mono CJK SC", Consolas, monospace`。正文 17px，行高 1.7。手机「小 / 标准 / 大」改为 16 / 17 / 18px，三档仍拉开，标准档落在 16–17px。代码块继续 13px，表格继续 14px，避免窄屏把等宽字撑出容器。

## 间距、圆角、阴影、动效

间距以 4px 为步长：4、8、12、16、20、24、32、40、48。阅读列和输入栏都是 `72ch`，在同一水平内边距里居中。

| 角色 | 圆角 | 阴影 |
| --- | --- | --- |
| 用户容器 | 18px | `--glass-shadow-soft`，很轻 |
| 助手正文 | 0 | 无 |
| 输入栏 | 22px | 轻浮起 |
| 菜单、设置 | 16px | 轻浮起 |
| 图标按钮 | 10px | 无 |
| 故事胶囊 | 999px | 无 |

颜色、间距、圆角、阴影和正文字号走变量。已有的 `--glass-*`、`--message-*`、`--mobile-*` 保留名字，避免把存储和测试依赖的钩子拆掉。

悬停和菜单只用 160ms 透明度或颜色。`prefers-reduced-motion: reduce` 把动画和过渡压到几乎为 0，滚动改为 `auto`。焦点环是 2px 强调色，偏移 2px；输入栏用整框的 3px 淡强调环，而不是闪动。

## 线框

桌面：侧栏约 272px，主区居中 72ch。助手没有头像列和卡片。用户短容器靠右。输入栏与正文同宽，贴底，发送按钮在框内。

```text
[ 侧栏        ] [        72ch 正文           ]
[ 名称       ] [ 标题                       ]
[ 新对话     ] [ 助手段落，无框             ]
[ 历史       ] [              (用户短容器) ]
[ 设置       ] [ [ 输入………………… 发送 ] ]
```

手机 ≤819px 侧栏改为滑出。≤520px 时标题下的故事面板仍按原规则隐藏，输入栏里的「故事」按钮保留。阅读列在这一档宽于视口时收缩为内容宽，不产生页面横向滚动。

## 自我修订

- 助手「AI」方标只是装饰，会从布局里拿掉，节点仍留给现有渲染，不改消息脚本。
- 模型按钮上的绿色圆点没有状态来源，最后再删。文件夹示例会弹出说明，脚本也依赖那些节点，所以保留。
- 玻璃模糊留给侧栏、顶栏、输入栏、模型菜单和设置，强度降低。消息本身不再模糊。
- 不改 `state.js`、IndexedDB、备份、模型目录和 `marked` → DOMPurify。
- 手机真机键盘无法在这台云环境里按下，视口验收不能代替它。
